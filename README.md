# EGF splicing kinetics

Are EGF-induced changes in PSI genuine splicing decisions, or turnover effects of gene induction?

PSI measures the mRNA pool, not the spliceosome's decision. Transcriptional induction (more pre-mRNA) combined with different isoform stability (e.g. NMD) can shift PSI without any change in the inclusion/skipping ratio of newly made transcripts. This repo combines three readouts from the same BAM files to tell the two cases apart:

| Readout | What is counted | Tool |
|---|---|---|
| Expression | reads per gene | featureCounts → DESeq2 |
| Splicing | inclusion / skipping junctions (PSI, ΔPSI) | rMATS |
| Production | intronic vs exonic reads | eisaR (EISA) |

## Data

Kiselev et al. 2015, *Nucleic Acids Research* (GEO: GSE69822).
MCF10A cells stimulated with EGF, bulk RNA-seq time course (18 samples).

## Reference

- Genome: GRCh38.p14 primary assembly (GENCODE release 50)
- Annotation: gencode.v50.primary_assembly.annotation.gtf (comprehensive)
- HISAT2 index built from the genome only; known splice sites (698,580) extracted from the GTF and supplied at alignment time.

## Library type

- Single-end, unstranded. Verified on SRR2061414 with featureCounts:
  Assigned -s 1 = 14,660,453 vs -s 2 = 14,692,104 (~50/50).
- Use featureCounts -s 0 and rMATS --libType fr-unstranded.

## Reproducing

1. Create the environments: `conda env create -f envs/<env>.yml`
2. Run the scripts in `scripts/` in numerical order.

## Caveats

- Poly(A) library: few intronic reads, so the EISA signal is limited.
- Replicates may be technical: DESeq2/rMATS statistics may be optimistic.
- This is a pipeline exercise, not a publishable result.
